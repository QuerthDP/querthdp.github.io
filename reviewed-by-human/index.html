Reviewed by Human

Some of my comments, pull requests and issues on GitHub and Jira are written with the help of Claude Code, and some I write myself and have Claude Code fact-check. I mark them with badges so you can tell how much of my own attention went into each one.

The badges

Claude Code wrote this text and posted it on my behalf. I asked for it to be posted, but I may not have read every word before it went out.

Claude Code wrote the text, and I went through its content and agree with it. Either we worked it out together, or I read it and explicitly approved it. I stand behind it as if I had typed it myself.

I wrote this text myself. Claude Code then checked its claims against the code and earlier discussions, and fixed typos or wording only where I agreed.

On Jira, where badge images do not render, the same marks appear as a plain line: “Generated with Claude Code · Reviewed by Human”.

When there is no Reviewed by Human badge

A post carries only the Claude Code badge when it is routine, for example:

  • changelogs listing what a new push to a pull request changed,
  • a batch of short replies to review comments that I asked to be answered at once,
  • comments that only trigger a bot or a CI job.

Such posts are still sent at my request, and I am still responsible for them. The missing badge only means I did not review that particular text closely.

Pull request descriptions

A pull request description gets the Reviewed by Human badge once I have looked through the pull request itself, not only its description. Until then it carries only the Claude Code badge.

Something looks wrong?

If a post with any of these badges is unclear or mistaken, mention @QuerthDP in a reply and I will answer it myself.
